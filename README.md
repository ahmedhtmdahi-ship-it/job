# JobPilot — Ahmed Hatem Dahi

Windows local job search and application review assistant. Work in progress, NOT a production auto-apply tool.

## Planned scope
Arabic desktop UI, SQLite history, CSV/manual URL import, deterministic offline matching without paid AI, and mandatory per-application review. The 24 requested platforms are targets, not verified integrations. No unattended submission or invented confirmation.

## Verified 2026-11-10
The v3 source archive passed 16 core tests and 8 matching tests on Linux. Windows execution, real site adapters, live submission, and EXE build remain unverified. The complete source archive has NOT been uploaded to this repository yet.

## Privacy
Do not commit private CVs, certificates, contact data, portfolio archives, credentials or browser sessions. Source-only sanitized publication required.
