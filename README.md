# أحمد حاتم — الوظائف والبورتفليو

## تنزيل النسخة الأصلية من GitHub

من فرع `codex/job-desktop-0.3` اختر **Code → Download ZIP**، ثم فك ملفات المستودع كاملة.
شغّل `distribution/windows/INSTALL_WINDOWS.cmd` ليجمع أجزاء حزمة Windows ويتحقق من بصمتها ويفكها.
بعدها افتح `distribution/windows/ready/AhmedHatemJobs-Windows-x64/AhmedHatemJobs.exe`.
لا تحتاج تثبيت Python لهذه الطريقة. الأجزاء التسعة تحفظ نفس حزمة Windows الأصلية دون تغيير محتواها.
حزمة المدخلات الأصلية كاملة موجودة في `inputs/Ahmed_Hatem_Codex_Handoff.zip`.
المراجعة التفصيلية والتكاملات الحية ما زالت مفتوحة؛ راجع `UPLOAD_STATUS.md` و`docs/VALIDATION.md`.

برنامج محلي لـWindows 10/11 بنواة x64، بواجهة عربية RTL، دون AI أثناء التشغيل أو استضافة أو اشتراك. بياناتك تُحفظ تحت `%LOCALAPPDATA%\AhmedHatemJobs`.

## تشغيل الحزمة المحمولة

1. فك **الحزمة كاملة** في مجلد تملكه، ثم افتح `AhmedHatemJobs.exe`.
2. الحزمة الشخصية تتضمن مدخلاتك الأصلية؛ تُستورد محليًا مرة واحدة عند أول تشغيل بعد التحقق من بصمتها. لا تُرسل إلى أي موقع.
3. من «الفرص» اختر «بحث متعدد المصادر»، وحدد الكلمات والمواقع ثم ابدأ. يمكنك الإيقاف والاستئناف، ومراجعة سبب فشل كل مصدر بدل اعتباره صفر نتائج.
4. لتسجيل الدخول أو معاينة نموذج، يستخدم البرنامج متصفحًا مستقل الجلسة. يستخدم Edge/Chrome المثبتين عند عدم وجود Chromium؛ أو شغّل `SetupBrowser.cmd` لتثبيته.
5. `RunWithConsole.cmd` متاح لعرض أخطاء التشغيل إن تعذر فتح الواجهة. لا تحتاج تثبيت Python أو دفع اشتراك.

**الـEXE جرى تجميعه لـWindows وفحصه بنيويًا من Linux. لم يُشغّل على Windows في هذه الجلسة.** تفاصيل بصمات Python والاعتماديات والملفات في `BUILD_MANIFEST.json`. الملف غير موقع بشهادة تجارية. لا يوجد Installer يغير النظام.

## البحث وتجهيز الطلبات

الموصلات المنفذة للقراءة: Freelancer وLinkedIn وWuzzuf وBayt و20four7VA، وWorkable عند إدخال معرف الشركة. مصادر إضافية: Remotive وJobicy وRemoteOK وArbeitnow. جميعها مختبرة ببيانات محلية؛ **التجارب الحية للمصادر التسعة الافتراضية حُجبت بـHTTP 403 من شبكة بيئة التطوير**. هذا لا يثبت أنها تعمل على جهازك؛ راجع سجل كل مصدر. لا يوجد ادعاء بدعم تقديم آلي على هذه المواقع.

تظل المواقع الـ24 المطلوبة ضمن سجل منفصل بقدرات البحث والتقديم والبورتفليو والخدمات ومعرض الخدمة والشهادات. روابط Welo Data وCS Outsource وSira وSLICEY تحتاج تحديدًا منك في شاشة «روابط المواقع والحسابات»؛ لا تُخمن دومينات.

يمكنك إضافة فرصة أو تعديل إعدادات المطابقة، واستيراد CSV، وقراءة إعلان JSON-LD من رابط، وتصدير النتائج. الفرص لا تُحذف بسبب فشل المصدر، وهوية الموقع ومعامل Indeed jk محفوظان. التشابه بين موقعين يظهر كمراجعة محتملة ولا يحذف الفرص تلقائيًا.

حد الأجر 5 USD/ساعة، وميزانية التقديم المدفوع صفر بما فيها Connects. الأجر غير المعلن والعملات غير المؤكدة تبقى للمراجعة؛ لا تحويل افتراضي للرواتب أو المشروعات الثابتة. لا حد يومي لعدد الطلبات. ذكر Remote لا يثبت أهلية مصر.

## المراجعة والتسليم اليدوي

اختر فرصة ← جهّز طلبًا ← راجع النص والأهلية والأجر ← اختر ملفاتك والأسئلة ← احفظ ← اعتمد النسخة.

قوالب عربية وإنجليزية قابلة للتعديل تعتمد على حقائق CV، دون توليد AI أو اختراع مدة أو عملاء. تُختار نسخة CV المناسبة بقواعد واضحة، وتُقترح ملفات البورتفليو دون إرفاقها تلقائيًا. نسخ العمل تصحح الهاتف ونهاية IdeaSpace مع حفظ الأصول.

«معاينة» تملأ الحقول المعروفة والمرفقات التي عيّنتها فقط، ولا تضغط إرسال. أي أسئلة غير معروفة تعود للمراجعة. الإجابات المحفوظة تُعاد بنطاقها؛ لا يُستخدم جواب عام لحقوق العمل بدل جواب دولة محددة. الموافقات والحقول المخصصة تُترك لمراجعتك.

«بدء تسليم يدوي بعد الاعتماد» يسجل المحاولة **قبل** فتح الموقع. أنت تراجع النموذج النهائي وترسل بنفسك، دون صرف أرصدة. البرنامج لا يعد إغلاق المتصفح أو صفحة شكر نجاحًا. النتيجة تبقى معلقة حتى تسجل رقم طلب ورابط إيصال محددًا راجعته بنفسك، أو تؤكد بعد مراجعة سجل الموقع أنه لم يُرسل. الإيصال مسجل كتأكيد منك وليس تحققًا آليًا من الموقع. لا إعادة تلقائية للمحاولات غير المؤكدة.

كل تغيير في المحتوى أو الإجابات أو الوجهة أو المرفقات أو التكلفة يبطل الموافقة. تغيير بيانات المتقدم أو تحديث فرصة معتمدة يستلزم المراجعة، ولا يفتح محاولة سابقة غير مؤكدة للتكرار. يمكنك تصدير حزمة محلية بالنص والمرفقات المختارة فقط، موسومة بأنها لم تُرسل.

## البورتفليو والشهادات

مشروعاتك وشهاداتك مفهرسة. اختر المشروع أو الشهادة وجهز مسودة للوجهة، ثم اختر ملفاتها المقترحة. يمكن فصل صفحات الشهادات دون تعديل المحتوى، وتحويل نسخة CV إلى PDF نصي محلي مع مراجعة التنسيق، وإنشاء نسخة صورة بحجم جديد مع معاينتها وحفظ الأصل.

رفع مشروع بورتفليو ونشر خدمة وإضافة معرض خدمة وإضافة شهادة عمليات مستقلة. النشر الفعلي **يدوي**؛ قيود كل منصة غير المتحقق منها لا تُختلق. تحقق من الحقوق والمصدر والحقول قبل النشر. دراسات البيانات العامة ليست ادعاء أعمال عملاء مدفوعة.

تأكيدك أن الأسماء والسجلات تخص الشخص نفسه محفوظ. شهادات Saad ليست محجوبة بسبب اختلاف الاسم وحده، ولا تُعدّل أسماؤها. الهاتف المعتمد +201144064593، ونهاية IdeaSpace أكتوبر 2026.

## الجدولة والخصوصية

يمكن جدولة قراءة روابط الإعلانات والبحث متعدد المصادر بالإعدادات المحفوظة. الجدولة معطلة افتراضيًا وتعمل فقط والبرنامج والجهاز يعملان ومتصلان بالإنترنت. إغلاق البرنامج يوقفها؛ لا تعمل والجهاز مقفول. لا تقديم أو نشر مجدول.

جلسات المتصفح مستقلة عن ملف Chrome الافتراضي، ويمكن مسح جلسة الموقع من الواجهة. النسخ الاحتياطي والاستعادة يشملان البيانات والأصول ونسخ CV المُدارة، ويستبعدان browser profiles وcookies. ملفات مرفقات خارج مجلد البرنامج تُحفظ منفصلة أو يعاد اختيارها بعد الاستعادة. النسخة تحتوي بياناتك الخاصة؛ احتفظ بها محليًا.

CSV يدعم `title,url,company,description,location,currency,pay_unit,pay_min,pay_max,eligibility,expires`. الوحدة `hour/month/fixed` والأهلية `unknown/eligible/ineligible`. مثال في `tests/fixtures/opportunities.csv` ضمن المصدر.

## بناء المصدر والاختبار

ثبّت Python 3.12 ثم شغّل `scripts\setup_windows.bat` و`scripts\run_windows.bat`. للبناء بـPyInstaller: `powershell -File scripts\build_windows.ps1`. يوجد Windows CI يدوي مرفق؛ لم يُشغّل هنا.

لإعادة الحزمة المحمولة من Linux أو Windows، ثبت ziglang==0.13.0 في بيئة البناء ثم شغّل:

```text
python scripts/build_portable_windows.py --cache <cache> --output <new-output> --input-bundle <handoff.zip>
python scripts/verify_portable.py <new-output>/AhmedHatemJobs-Windows-x64
```

سكريبت البناء يتحقق من SHA512 الرسمي لـCPython وSHA256 لكل wheel من PyPI. الاعتماديات المباشرة مثبتة الإصدارات، وrequirements-linux.lock يسجل بيئة التطوير المرصودة. الاختبارات: `QT_QPA_PLATFORM=offscreen python -m pytest -q` على Linux، و`python -m pytest -q` على Windows.

راجع [نتائج التحقق](docs/VALIDATION.md) و[تغطية المصادر](docs/COVERAGE.md) و[التراخيص](docs/THIRD_PARTY.md). المواصفات الأصلية محفوظة دون ادعاء اكتمال اختبارات Windows أو التكاملات الحية.

## تحديث التحقق 0.3

نجح 105 اختبارات محلية. أضيف محرك مراجعة النموذج النهائي والإرسال المربوط بالموافقة، واختُبر POST وإيصال خاص وانقطاع بعد الإرسال على صفحات محلية فقط. وضع الاختبار لا يسمح بالإرسال على دومينات حقيقية. تظل موصلات المواقع غير المتحقق منها على التسليم اليدوي.

في المتصفح يوجد زران للمعاينة فقط: إعادة ملء الحقول المعروفة بعد تسجيل الدخول/التحقق الأمني، وحفظ قيم النموذج الحالي لعرضها داخل البرنامج. لا يضغطان إرسالًا، ولا يحفظان كلمات السر أو الحقول المخفية.

الـEXE وواجهة Windows Qt اشتغلا فعليًا تحت Wine 10، ومعهما اختبار استيراد ملفاتك وCV وشهادة وتصدير واستعادة نسخة احتياطية في مسار عربي. هذا اختبار توافق، وليس تحققًا على Windows حقيقي. التفاصيل في docs/WINE_COMPATIBILITY.md.
